# Vobiz Integrations & SDKs

> Connect Vobiz to leading AI voice platforms globally - Vapi, Retell AI, ElevenLabs, LiveKit, Pipecat, Rapida AI, and more via SIP trunking, REST APIs, and WebSocket streaming.

## Introduction

Vobiz is built ground-up for AI-first interconnectivity. Route telephone audio directly into any major AI voice platform using SIP trunking or WebSocket streaming - no custom bridges required.

## Prerequisites

Before integrating any platform:

<Steps>
  <Step title="Create a Vobiz account">
    Sign up at [vobiz.ai](https://vobiz.ai) and top up your balance.
  </Step>

  <Step title="Purchase a phone number">
    Buy an inbound/outbound number from [Phone Numbers](/docs/account-phone-number).
  </Step>

  <Step title="Create a SIP Trunk">
    Set up a trunk for your chosen platform. See [Trunks](/docs/trunks).
  </Step>

  <Step title="Follow the integration guide">
    Pick a platform above and follow its step-by-step setup guide.
  </Step>
</Steps>

## Getting Started

Not sure which platform to use? Here's a quick guide:

| Use case | Recommended platform |
| - | - |
| Production AI voice agent | [Vapi](/docs/integrations/vapi-dashboard) or [Retell AI](/docs/integrations/retellai-dashboard) |
| Lowest latency streaming | [LiveKit](/docs/integrations/livekit) |
| Realistic TTS voices | [ElevenLabs](/docs/integrations/elevenlabs) |
| Custom AI pipeline | [Pipecat](/docs/integrations/pipecat) or [WebSockets](/docs/integrations/websockets) |
| Open-source agent platform | [Rapida AI](/docs/integrations/rapida-ai) or [Dograh](/docs/integrations/dograh) |
| Indian-language agents, no telephony setup | [Sarvam](/docs/integrations/sarvam) |
| Browser softphone | [WebRTC Integration](/docs/integrations/webrtc-application-setup) |
| OpenAI GPT-4o voice | [OpenAI Realtime](/docs/integrations/openai-realtime) |
| Two-way agent on a number you already own | [Smallest AI](/docs/integrations/smallest-ai) |
| Outbound calling campaigns from a voice agent | [Agora](/docs/integrations/agora) |
| xAI Grok voice agent on your own number | [xAI](/docs/integrations/xai) |
| Google Gemini voice agent over WebSocket streaming | [Gemini Live](/docs/integrations/gemini-live) |
| Voice agent with Deepgram Flux STT and TTS | [Deepgram](/docs/integrations/deepgram) |
| Calling from a CRM, with AI agents | [Expedify](/docs/integrations/expedify) |
| Agent softphone and call logging in a helpdesk | [Zendesk](/docs/integrations/zendesk) or [Freshdesk](/docs/integrations/freshdesk) |
| Calling from a CRM record, logged against the contact | [HubSpot](/docs/integrations/hubspot) or [Pipedrive](/docs/integrations/pipedrive) |
| Telephony inside Zoho CRM, Desk, Recruit or Bigin | [Zoho](/docs/integrations/zoho) |
| Softphone inside Salesforce Lightning, over Open CTI | [Salesforce](/docs/integrations/salesforce) |
| Softphone in ServiceNow, logged to the interaction table | [ServiceNow](/docs/integrations/servicenow) |
| Calls logged as tasks in a project tool | [ClickUp](/docs/integrations/clickup) |
