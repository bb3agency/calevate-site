# Beep detection

> You can use the Wait element to aid leaving voice mails on answering machines by adding an extra parameter called beep and setting it to true.

You can use the Wait element to aid leaving voice mails on answering machines by adding an extra parameter called beep and setting it to true.

## Example

### Response

```xml theme={null}
<?xml version="1.0" encoding="UTF-8"?>
<Response>
    <Wait length="10" beep="true"/>
</Response>
```
