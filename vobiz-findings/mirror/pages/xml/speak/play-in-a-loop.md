# Play in a loop

> Example of the Vobiz Speak XML element with looping - tells Vobiz to say the word Wow three times in a row using the loop attribute on the Speak verb.

## Example

### Response

```xml XML Response theme={null}
<Response>
    <Speak loop="3">Wow</Speak>
</Response>
```
