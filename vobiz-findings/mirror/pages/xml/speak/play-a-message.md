# Play a message

> Example of the Vobiz Speak XML element - when an inbound call is directed to this document, the Speak verb plays a TTS message to the caller.

## Example

### Response

```xml XML Response theme={null}
<Response>
    <Speak>Vobiz - Simple, AI-first telephony for voice agents.</Speak>
</Response>
```
