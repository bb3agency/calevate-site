# Using Bolna AI with viaSocket

> Learn how to integrate Bolna Voice AI with viaSocket to create custom workflows, enabling seamless automation between Bolna and other applications.

Bolna is listed as a native integration on [viaSocket](https://viasocket.com/integrations/bolna), so you can add it as a node in any viaSocket workflow. With this integration, Bolna can trigger actions in thousands of apps connected through viaSocket, making your processes more efficient and reducing manual work. It helps streamline workflows and improve productivity by automating repetitive tasks.
