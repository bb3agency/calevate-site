| Section D check | Made by |
|---|---|
| More than one question or caller action in a turn | `multi_question_line`, `multi_action_line` |
| Consecutive turns opening with the same acknowledgement | `lint.same_opener_problems`, `lint.mistake.same_opening` |
| An exact repeat of an agent sentence | `lint.repeated_line_problems` |
| A known field asked for | `known_value_asked` |
| A step marked done with no caller words meeting its done signal | a call's transcript, not a script: out of scope here |
| A branch condition equal to a step title | `fake_branch` |
| A bracketed duplicate name | `register_in_line`, `lint.bracket_problems` |
