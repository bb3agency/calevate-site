## Not fixed

- **The slowdown reason is never shown** (`LoadShedPanel.tsx`, the reason field's hint). The
  hint says "Whoever finds the platform slowed reads this…", but `PlatformStateOut` has no
  load-shed reason. `set_platform_status` stores `halt_reason` only with the halt switch, and
  `audit_log` has no summary column. So the typed reason appears on no screen. Fixing this
  needs a stored column (a migration), which this round does not allow. Until then, either
  correct the hint or add the column.
- **A failed config poll can throw away an open edit** (`config/configField.ts::configState`,
  where error comes before data). On a failed 60-second poll every section is replaced by
  "unreadable", so an open `ConfigForm` unmounts and loses its draft and reason. The current
  behaviour is a deliberate choice (it never shows a stale table as current), so I did not
  change it. A narrower option would keep an open form mounted with Save held. This is the
  founder's or design's call.
- **Call words** (`call-words/CallWordsScreen.tsx`) has the same shape: a failed focus refetch
  replaces the screen, and an open editor loses its text. P3, not changed for the same reason.
- **Raw Meta limit code** (`whatsapp/WhatsAppAdminScreen.tsx:165`) prints
  `messaging_limit` exactly as stored (Graph `whatsapp_business_manager_messaging_limit`,
  e.g. a `TIER_…` token). UNVERIFIED: I did not check Meta's current enum values this
  session (hard rule 11), so I have not written labels for them.
- **Healer overview** (`healer/HealerScreen.tsx:118`) shows cached data beside a failed
  refetch. It has no poll and makes no all-clear claim, so I left it.
- The outbox replay result prints the raw job name after "Resent:". This is deliberate:
  reading back the server's scope is how a wrong scope gets noticed.

Checked and found sound (no change): the big red switch's typed word, reason and step-up

model price panels (units are labelled ₹/min, US$ or ₹ per million tokens, ₹ per 1,000
characters); voice comparison reads, which all offer a retry.
